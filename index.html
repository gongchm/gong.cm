  17. Implementation of Polar Form Algorithms with the Rectangular Form Complex Number
    GONG Chengming. IEEE PES General Meeting (PESGM 2010), 2010. PDF

    Power system analysis algorithms under polar coordinates are traditionally implemented with the polar form complex number, which is abstracted as phase and magnitude. This paper addresses a method to implement the polar form algorithms with the common rectangular form complex number, which is abstracted as real and imaginary parts. The key points of the addressed method are to express the derivatives to polar components under rectangular coordinates, and to rotate and stretch a complex number under rectangular coordinates. With the addressed method, the polar form algorithms can be implemented with direct complex operations and will share more components with rectangular form algorithms.

  19. A General Power System Topology Analysis Package and Its Applications
    Chengming Gong, Shuhai Feng, Xianfeng Xu, Yuefeng Liang, Hongwei Du. ICEE 2006, 2006. PDF

    Power system network topology analysis is a basic function in the Energy Management System (EMS). The task of traditional topology analysis function is mainly to build bus and island models for online network analysis modules, such as state estimation, contingency analysis and dispatcher power flow. In this paper, some new topological objects in the power system network, including bay, loop, route, etc, and model type of node, bus, extended-bus, primary bus and primary extended-bus are abstracted. A power system topology analysis (PSNTP) package is addressed based on the abstracted concepts. The package is implemented in a general way by applying several basic graph theory algorithms to different model types. Functions and interfaces provided by the package are listed and some ways to improve the package’s flexibility and efficiency are discussed in the paper. Application examples in Supervisor Control And Data Acquisition (SCADA) and state estimation modules show the package’s validity and value.

课题

综合能源管理 SaaS

以 SaaS 的形式为用户提供能源网络建模、数据采集定义、能源系统运行平衡分析、热点分析、在线优化策略和离线优化建议等功能。

新能源交直流混合微电网系统能量管理、经济调度和市场交易

计划 2018 年 1 月初在日充电量达到 200 万千瓦时量级的国内主要电动车充电服务网络之一试运行，为电动公交车提供充电优化服务，在满足车辆运营需求的同时，优化充电时间安排，主要在低谷和平价时段充电，降低电能成本，同时也实现充电的峰谷差和电网峰谷差的反向调节。下一步将通过分析微电网的能量平衡来降低损耗，进一步提高充电效率；继续推进电动车充放电基础设施的微网化，研究应用固定储能设施、分布式新能源发电，和电动汽车移动储能特性配合，以分布式发电预测、电动车出行需求和放电能力预测为基础，优化充放电安排，进一步降低电动车电能成本并提升充电基础设施的供电可靠性。已和具有新能源发电背景的售电公司达成合作，推进充放电基础设施和售电业务的结合，动态优化电动车充电服务价格、调节充电量的时空分布，提升交易计划完成率，降低电动车充电服务的电能成本；未来将通过固定储能和电动车移动储能的参与，在实现大规模电动车充电对电网更友好的同时，积极在辅助服务市场获取收益，在现货市场进行套利。

新能源交直流混合微电网系统运行控制

实现传统电网调控运行经验和电力电子技术的无缝衔接。电力电子器件具有调节快速、精准的特点，但是快速调节的副作用是系统惯性小，精准调节的副作用是控制增益大，这两点都将直接影响到系统的稳定性。通过把电力系统现有的一次调频有差调节等概念应用到电力电子化的微电网系统中，来实现微网系统的安全、稳定、灵活运行，支持各类电源、储能、换能和用能设备的灵活接入。通过系统中各类固定储能和移动储能的支持，实现负荷侧虚拟同步机特性。跟踪碳化硅等电力电子器件的发展，结合各类直流源荷的发展，不断提升电力电子变换系统的效率和复用能力，逐步过渡到使用多端口电力电子变压器作为交直流微网系统的核心部件。

物联网数据桥接器

综合能源管理和大量微电网设备特别是电力电子模块的智能运维都需要采集海量数据。该项目研发在物联网数据协议和系统云平台的消息总线之间的高效桥接，打通从海量小微传感器的数据采集到最终大数据分析的通道。系统具备单节点应对 10 万个以上链路数据传输的能力，并支持增加节点实现水平扩展。系统已于 2017 年底实现试运行，预计 2018 年年中在实际系统上规模化部署。
